# Файлы правил для установки

*Языки: [English](index.md) · **Русский** — Родитель: [индекс репозитория](../index.md)*

Готовые файлы правил. Агент, устанавливающий llm-wiki-tags, копирует их в целевой
репозиторий как `.claude/rules/llm-wiki-tags/` — см. шаг 1
[`INSTRUCTIONS.ru.md`](../INSTRUCTIONS.ru.md). Это **каноническая формулировка**
соглашения: `README.ru.md` его описывает, а эти файлы задают его как правила.

Claude Code подгружает каждый `.md` из `.claude/rules/` проекта на каждой задаче.
Файл, у которого во front matter есть поле `paths:`, подгружается **только**
когда затронут подходящий файл — так правила по языкам не висят в контексте, пока
не применяются. `paths:` принимает список или строку через запятую с
`{a,b}`-раскрытием (`paths: "**/*.ts, **/*.tsx"`).

## Файлы

Грузятся всегда:

- [`wiki.md`](wiki.md) — дерево `index.md`, «сначала читай», «обновляй по ходу».
- [`docs-layout.md`](docs-layout.md) — дерево `docs/`: external, specification,
  implementation, testing, requests.
- [`tags.md`](tags.md) — формат тэга, иерархия, реестр `docs/tags.md`, команды
  поиска.
- [`glossary.md`](glossary.md) — словарь `docs/terms.md`: поиск по смыслу до того,
  как назвать, одно определение на термин, синонимы ведут к основному.

Грузятся по языку (копируй только те, что нужны репозиторию):

- [`code-tags-java.md`](code-tags-java.md) — `paths: ["**/*.java"]`.
- [`code-tags-python.md`](code-tags-python.md) — `paths: ["**/*.py"]`.
- [`code-tags-golang.md`](code-tags-golang.md) — `paths: ["**/*.go"]`.

У каждого файла есть близнец `.ru.md` с тем же содержанием по-русски: ставь один
язык, убирая `.ru` из имени файла. Перекрёстные ссылки внутри файлов используют
установленные имена (`wiki.md`, `docs-layout.md`, `tags.md`), поэтому после
копирования они резолвятся без правки.

Для языка, у которого нет файла `code-tags-*.md`, напиши его по
[`languages/`](../languages/index.ru.md) — там то же самое изложено прозой.

Сам этот индекс в целевой репозиторий не копируется: он про этот репозиторий, а
внутри `.claude/rules/` он подгрузился бы как правило.
